# 小黑猫桌宠

根据提供的视频和键盘照片重新绘制的 Windows 桌宠。圆脸小猫、灰阶立体机械键盘和鼠标都用矢量绘制，可以独立活动；并非原视频程序或原作者的美术文件。

## 3.2 互动小手与挠脖子

- 光标移到可互动部位时立即变成对应的小手：头顶/脸颊是张手抚摸、脖子是弯食指挠痒、肚子是双指挠痒、爪子是食指轻碰、尾巴是轻捏。
- 脖子新增独立的挠痒反馈：停留会眯眼、抬下巴、轻轻侧蹭，享受时会呼噜；轻点也会抬下巴。
- 开始拖动后变为抓手；离开小猫、打开菜单、暂停跟随、关闭摸摸或开启鼠标穿透时恢复普通光标。
- 光标和互动使用同一套部位判定，会跟随猫的身体动作；手势只用于小猫窗口。小手缓存后复用，不会每帧重新绘制。

## 3.1 响应性修复与诊断

- 将呼噜声的播放、停止移到后台线程，界面不再等待声音设备响应；连续切换只处理最新状态。
- 保留原有动作和 12 种毛色。菜单新增“打开诊断日志文件夹”。
- 界面连续约 8 秒不处理消息时，自动将线程位置写入 `%LOCALAPPDATA%\LittleBlackCat\hang-trace.log`。日志不记录输入文字、键码或屏幕内容。
- 新增 `--mute` 无声启动选项；可以随时在菜单中重新开启“打呼噜声音”。

本机已复现并修复“声音调用阻塞界面”的路径；另一台电脑提供的旧日志只有正常启动和退出记录，尚不能确认远端卡死就是同一原因。若新版仍出现“未响应”，先等约 10 秒再关闭，保留同目录中的 `app.log` 和 `hang-trace.log` 用于继续定位。便携包内的“打开诊断日志.cmd”可以直接打开该目录；“无声启动.cmd”可用来对比声音关闭后的表现。

## 轻点、喂食、逗猫与 12 种毛色

- **轻点不同部位**：点头顶会吃惊，点脸颊会蹭，点肚子会扭动，点爪子会缩爪，点尾巴会回头。停留抚摸与轻点是不同反应；拖动仍然调整位置。
- **连续轻点头顶三下**：触发短暂晃脑袋和小星星彩蛋，随后恢复正常。
- **右键 → 陪它玩 → 喂一条小鱼干**：小猫捧起鱼干，吃完露出满足表情。
- **右键 → 陪它玩 → 逗毛线球**：目光追着弹动的毛线球，伸爪拍一拍。小游戏会自行结束，打字依然响应。
- **右键 → 小猫毛色**：黑猫、三花、布偶、橘猫、银虎斑、狸花、英短蓝猫、黑白燕尾、奶牛猫、异瞳白猫、暹罗、玳瑁，共 12 种；包含条纹、花斑、白袜、重点色和异瞳。
- 菜单中还可选“换个随机毛色”，不会抽到当前毛色；切换立即生效，并保存选择。

交互参考了《会说话的汤姆猫》的触碰反馈、重复互动与喂食：[早期案例介绍](https://www.intel.com/content/dam/develop/external/us/en/documents/case-study-outfit7-and-talking-tom-660128.pdf)、[Outfit7 官方游戏说明](https://play.google.com/store/apps/details?id=com.outfit7.talkingtom)。这里用自己的小猫造型重新实现，并延伸出适合桌面的短时毛线球动作。变声复读适合作为手动录制后回放的独立功能，当前版本未接入麦克风。

## 身体动作、摸摸和毛色

- 移动鼠标和敲键时，肩膀、腰身与头部一起侧倾、扭动和轻微起伏；爪子落点继续对准键盘与鼠标。
- 修复脚掌和前爪轮廓内部漏色，身体重叠时仍有清晰描边。
- 鼠标在身体部位停留片刻即可摸摸：头顶眯眼、脸颊蹭蹭、肚子怕痒、爪子缩起、尾巴摆动。摸头或脸颊一会儿也会打呼噜。
- 右键 → **小猫毛色**：可切换完整花纹。三花有奶白、橙色与黑色花斑；布偶有蓝眼、重点色耳朵和四肢、白色脸纹。
- 毛色会记住，下次启动继续使用。右键菜单可关闭“鼠标停在身上时摸摸”；拖动小猫、打开菜单和鼠标穿透时会暂停摸摸。

## 这次外观调整

- 改成圆脸、短耳和小身子，去掉成年猫的厚腮、嘴边褶线和粗脖子。
- 保留略宽眼距，用圆眼、柔和瞳孔和极小中性嘴表现“可爱但不聪明”的放空表情。
- 鼠标移近身体，缩小活动范围；鼠标臂缩短，前臂和爪子加粗。
- 前后四肢加暖白轮廓线，重叠和快速移动时更易区分。
- 键盘缩小，按照片重画灰白到深灰的98键布局，加入键帽侧壁、倒角和厚底座。
- 数字区有独立落点，数字区 Enter 与主键区 Enter 分别响应。

## 启动

源代码仓库不包含打包程序。使用已发布的程序时，请从仓库的 Releases 下载；尚无发布版本时，可以按下文从源码运行或自行打包。

本地打包后，双击 `release/小黑猫3.2.exe`；使用便携包时，解压后双击其中的程序。便携运行，不需要安装 Python，也不需要联网。启动前先退出旧版，避免单实例限制使新版无法打开。启动后小猫出现在屏幕右下角，任务栏通知区域中会出现绿色猫眼图标。重复打开不会生成第二只猫。

## 试一试

- 移动鼠标：眼睛追光标，头和身体稍慢跟上，猫爪推动自己的小鼠标。
- 在其他软件里打字：爪子敲对应键位，键帽亮起，字母气泡浮起。
- 连续快速敲键：出现几道短暂、淡出的猫爪残影。
- 同时移动鼠标和打字：一只爪子操作鼠标，另一只爪子继续敲键盘。
- 默认 45 秒没有操作：闭眼休息、轻微呼吸、播放低音量的合成呼噜声；任何新输入都会唤醒。

## 操作

- 按住小猫拖动：调整位置。
- 右键小猫或托盘图标：毛色、摸摸、大小、残影、声音、休息时间、鼠标穿透、暂停和退出。
- 托盘图标可能收在 Windows 通知区域的小箭头内。
- 开启鼠标穿透后，使用托盘菜单恢复，或按 `Ctrl+Alt+Shift+M`。
- `Ctrl+Alt+Shift+Q`：退出小猫。
- “试试打个盹”能快速预览睡觉；点完后暂时不要移动鼠标。

只在内存中处理键码、按下状态和鼠标坐标，不保存输入文本。设置和运行错误日志保存在 `%LOCALAPPDATA%/LittleBlackCat`，日志不包含按键内容。不会设置开机启动。

## 实现范围

采用 2D 参数动画复现视频的主要观感，转头是头部偏转与五官位移；呼噜为本地合成音效。双爪无法同时覆盖大量按键，因此高速输入会合并动作，所有键位反馈与猫爪残影共同表现快速敲击。

## 源码运行

Python 3.10+，Windows 10/11。

```powershell
python -m pip install -r requirements.txt
python black_cat.py
```

`animation.py` 管理动作、触摸、轻点和残影，`cat_renderer.py` 绘制猫、花纹和鼠标并判断触摸部位，`play_art.py` 绘制小鱼干、毛线球和互动效果，`skins.py` 定义毛色，`keyboard_art.py` 绘制立体键盘，`scene_layout.py` 统一身体和触点坐标，`native_input.py` 接收系统输入，`sound_player.py` 隔离声音设备调用，`runtime_diagnostics.py` 记录界面阻塞位置，`black_cat.py` 管理桌面窗口和菜单。

```powershell
python -m unittest discover -s tests -v
New-Item -ItemType Directory -Path analysis -Force | Out-Null
python black_cat.py --demo --smoke-test 5 --capture analysis/demo.png --report analysis/smoke.json
python black_cat.py --demo --skin calico
python black_cat.py --play feed --skin orange_tabby
```

`tools/` 中的预览工具可选使用；生成 GIF 的 `render_motion_preview.py` 和 `render_play_preview.py` 还需安装 Pillow（`python -m pip install Pillow`）。`render_preview.py` 默认生成当前版本预览，只有显式传入 `--baseline 旧版绘制文件路径` 才生成版本对比，不依赖本机历史备份。

## 打包

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name 小黑猫3.2 --icon assets/black-cat.ico --add-data "assets/purr.wav;assets" --distpath release black_cat.py
```

演示模式的输入由应用内部生成，不会向其他程序发送按键。
